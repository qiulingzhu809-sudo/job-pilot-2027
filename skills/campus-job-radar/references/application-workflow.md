# 安全网申流程

## 1. 读取目标与标准资料

确认公司、职位、官方 URL、希望停在提交前还是准备提交，以及是否计划上传附件。优先从工作台“网申资料库”读取用户已保存的标准资料；它是姓名、联系方式、证件、教育和通用求职偏好的主来源。简历只补充工作经历、项目经历、技能和奖项，不把简历解析结果直接视为已确认的基础资料。

资料库缺少网站必填字段时，整理缺项并向用户询问。没有明确来源时暂停，不从岗位描述、简历上下文或其他网站推测个人事实。

## 2. 建立字段映射

读取可见表单，先输出映射表：网站字段、拟填内容、来源、状态。状态使用 `已确认`、`需要选择`、`缺失`、`不适用`。不要在建立映射时输入任何个人信息。

## 3. 输入前确认

列出即将传给该招聘网站的敏感字段类别，例如姓名、电话、邮箱、地址、证件、教育经历、项目经历和工作经历；分别注明来源为“标准资料库”“指定简历”或“用户本轮确认”，并列出缺失字段。得到针对当前公司和岗位的明确确认后才填写。

## 4. 填写与复核

优先按标签、占位符和可访问结构定位控件。关键字段写入后重新读取值；不覆盖用户已有内容。登录、动态验证或验证码出现时暂停，不重复尝试。

上传简历、作品集、照片或证书前，展示文件名、文件类型和目标网站并单独确认。不要把求职资料写入代码仓库。

## 5. 最终提交闸门

默认停在最终提交按钮之前，汇总必填字段、附件、隐私声明和未确认回答。只有用户在此时明确说“确认提交”才点击。成功后只记录页面可见的申请编号、成功提示和下一步，不记录密码或验证码。
